# Notas das reuniões semanais

Cada reunião publicada pelo botão "Publicar no painel" do Resumo executivo vira um arquivo `AAAA-MM-DD.md` nesta pasta e aparece no "Registro das reuniões" da página `resumo.html`.

Para corrigir uma nota, edite o arquivo pelo GitHub (lápis → editar → commit). Para apagar, exclua o arquivo.
